# 变更定级门禁（S0.5）

任何非「用户已明确档位」的任务，在写 planning / fixes 或业务代码**之前**通过。

## 流程

1. Agent 提议档位（T0–T3）+ slug + 理由
2. **停止**，请用户确认
3. 用户确认 → 落盘 `00-change-meta.md` 或 `fixes/<slug>/00-bugfix.md`
4. 进入对应 workflow

**禁止**未经确认档位就开始编码。

## 提议格式

```markdown
## 变更定级提议
| 提议档位 | T0 / T1 / T2 / T3 |
| slug | xxx |
| 理由 | ... |
请确认档位是否正确。
```

## 检查清单

- [ ] 已对照四档定义
- [ ] 用户已确认档位
